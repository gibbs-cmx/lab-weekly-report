# 주간보고 시스템 요구사항 (v0.1)

## 사용자

| 역할            | 할 수 있는 일                                                                                                                     |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 구성원 (MEMBER) | 로그인, 주간보고 작성/임시저장/제출, 내 보고서 조회, 비밀번호 변경                                                                |
| 관리자 (ADMIN)  | 프로젝트 등록/수정/종료/삭제, 사용자 등록/수정/비활성/비밀번호 초기화, 주간 제출 현황, 보고서 상세/재오픈, 프로젝트별 참여율 집계 |

## 주간보고

- 주 단위 (월요일 시작, KST). 사용자 × 주 당 1건
- 항목 = 프로젝트 1개 + 참여율(%) + 이번 주 수행 내용 + 다음 주 계획. 같은 주에 같은 프로젝트 중복 불가
- 보고서 단위 메모: 이슈 · 건의 · 기타
- 임시저장: 형식 검증만 (합계 100% 초과 불가)
- 제출: 항목 1개 이상, 참여율 합계 정확히 100%, 수행 내용 필수
- 제출 후에도 본인이 수정 가능: 내용을 고쳐 "다시 제출" (제출 상태와 최초 제출 시각 유지, 제출 기준 검증 동일 적용)
- 제출된 보고서는 임시저장으로 되돌릴 수 없음. 제출 취소는 관리자 재오픈으로만
- 미래 주차 작성 불가, 과거 주차는 작성 가능
- 편의 기능: "지난주 불러오기" — 지난주 프로젝트/참여율 + 지난주 "다음 주 계획"을 이번 주 "수행 내용"에 채움

## 집계 · 통계

- 제출 현황: 재직 중인 구성원(MEMBER) 전원의 주간 상태 (제출 / 작성중 / 미작성)
- 통계 (기간 지정: 이번 달 / 최근 12주 / 올해 / 직접 입력, 제출된 보고서만 반영)
  - 요약: 총 투입(인·주), 평균 제출률, 미제출이 있는 구성원 수
  - 프로젝트별: 투입 비중, 프로젝트별 인·주와 참여 구성원의 평균 참여율
  - 구성원별: 제출률, 프로젝트별 평균 참여율(제출한 주 평균, 합계 100%), 인·주, 미제출 주
  - 월별: 구성원 × 프로젝트의 월 평균 참여율 (그 달에 제출한 주의 평균). 한 주는 목요일이 속한 달로 센다
  - 주차별 추이: 프로젝트별 투입 누적 막대, 제출률 막대, 표 보기
- 엑셀 내보내기 (관리자)
  - 제출 현황: 그 주의 보고서 전체 (프로젝트 항목 한 줄씩)
  - 통계: 구성원별 / 월별 참여율 / 프로젝트별 / 주차별 / 보고서 원본 시트
- 내 통계 (구성원, "내 보고서" 화면): 제출률, 미제출 주, 프로젝트별 평균 참여율, 주차별 배분
- 정의
  - 인·주 = Σ(참여율 / 100) — 100% 로 1주 참여 = 1.0
  - 제출률 = 제출한 주 ÷ 제출 대상 주. 대상은 계정이 등록된 주부터 (그 전이라도 보고서가 있으면 포함)

## 계정

- 관리자가 사용자 등록 → 임시 비밀번호 1회 표시 → 첫 로그인 시 비밀번호 변경 강제
- 비밀번호: 8자 이상, 영문 대/소문자·숫자·특수문자 중 3종 이상
- 로그인 5회 실패 시 잠금 → 관리자 비밀번호 초기화로 해제

## 확인이 필요한 가정 (사용자 결정 대기)

1. **참여율 합계 100% 강제** — 근무시간 배분 개념으로 가정. 100% 미만 제출 허용이 필요하면 `REQUIRED_TOTAL_RATE` 규칙 변경
2. **프로젝트 참여자 지정 없음** — 모든 구성원이 모든 진행중 프로젝트를 선택 가능. 프로젝트별 참여 인원 배정이 필요하면 `project_members` 테이블 추가
3. **마감/알림 없음** — 미제출자 리마인드(메일/메신저)는 추후
4. **로그인 = 이메일** — 사번 등 다른 식별자가 필요하면 추가
